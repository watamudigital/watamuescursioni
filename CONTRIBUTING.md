# Collaborazione e sicurezza

Watamu Escursioni è una demo editoriale multilingua, **non** un sistema di prenotazione già operativo. Il contenuto non va messo in indice finché non siano verificati operatore, offerte e informazioni legali.

## Primo contributo GitHub
1. Apri una issue su cosa migliorare, senza condividere dati personali o segreti.
2. Crea un branch `content/tema-del-lavoro` partendo da `main`.
3. Modifica una pagina alla volta e verifica italiano, inglese, tedesco e francese.
4. Apri una pull request spiegando la modifica; allega screenshot mobile.
5. Fai approvare la PR prima di unire su `main`.

Non aggiungere chiavi API, credenziali di Vercel o Supabase, né numeri WhatsApp senza permesso. Non rimuovere `noindex` o `robots.txt` prima della validazione commerciale.
